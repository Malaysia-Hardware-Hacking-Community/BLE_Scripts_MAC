# Authors and contributors

WAMBLE is maintained by the
[Malaysia Hardware Hacking Community](https://github.com/Malaysia-Hardware-Hacking-Community)
and built by everyone who contributes to it.

Thank you to all contributors. The full, always-current list of people who have
contributed code is on the GitHub contributors page:
https://github.com/Malaysia-Hardware-Hacking-Community/WAMBLE/graphs/contributors

Contributions of every kind count, including bug reports, device compatibility
reports, and documentation, even when they do not show up in the code graph. If
you contributed something that is not reflected here and you would like to be
listed, please open a pull request adding yourself below.
